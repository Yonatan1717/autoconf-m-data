# Dokumentasjon

- `architecture.md` – arkitektur, segmentering og hovedkomponenter.
- `deployment.md` – anbefalt rekkefølge for klargjøring og utrulling.
- `testing.md` – verifikasjon av L2/L3, DMVPN, AAA, logging og overvåkning.
- `lab-limitations.md` – observasjoner der CML/virtuell IOS ikke nødvendigvis representerer fysisk målplattform.

Tjenestespesifikke installasjonsguider ligger under `services/`.
