# Eksempler

`demo_no_mpls.xlsx` er en sanert eksempelarbeidsbok. Secrets er erstattet med `CHANGE_ME_*`-verdier.

`generated/` viser et lite utdrag av hva generatoren produserer, slik at repoet kan inspiseres uten å kjøre generatoren først.

Generer alltid nye filer fra din egen lokale arbeidsbok før faktisk utrulling.
