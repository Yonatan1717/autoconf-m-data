# Generated output

Denne mappen fylles av `automation/generator/generate.py`.

Innholdet kan inneholde passordhashes, TACACS-/RADIUS-nøkler, SNMPv3-passord og IPsec-PSK-er avhengig av inputfilen. Derfor er innholdet ignorert av Git som standard.

Saniterte eksempler ligger i `examples/generated/`.
