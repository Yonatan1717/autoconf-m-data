# Manuelle templates

Disse malene er korte referansekonfigurasjoner for manuell lab/feilsøking. Den faktiske prosjektkonfigurasjonen bør normalt genereres fra Excel via `automation/generator/generate.py`.

- `cisco/` – AAA, 802.1X, logging, SNMPv3 og NTP.
- `ubuntu/` – eksempel på statisk management-adresse for sentral tjenesteserver.

Alle secrets er placeholders.
